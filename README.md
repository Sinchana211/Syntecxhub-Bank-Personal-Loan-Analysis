# Syntecxhub-Bank-Personal-Loan-Analysis


Bank Personal Loan Performance Analysis

Description

An end-to-end banking analytics project analyzing customer demographics, financial profiles, banking engagement, and personal loan acceptance using SQL Server and Power BI.

🛠️ Tools & Technologies

SQL Server / SSMS – Data preparation and dimensional modeling
Power BI – Data modeling, DAX measures, and dashboard development
Power Query – Data transformation
Data Visualization – KPI cards, bar charts, column charts, scatter plots, donut charts, and matrix analysis

📊 Dashboard Highlights

Total Customer Analysis
Average Income
Loan Acceptance Rate
Loan Acceptance by Education
Loan Acceptance by Age Group
Loan Acceptance by Family Size
Loan Acceptance by Income Level
Professional Experience Analysis
Credit Card Spending Analysis
Banking Engagement & Loan Acceptance

🎯 Business Objective

The objective of this project is to identify customer characteristics and financial behaviors associated with personal loan acceptance, helping banking teams better understand potential target customer segments.
